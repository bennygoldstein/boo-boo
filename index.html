How it works

Three steps, no setup ceremony.

  1. Download and open Boo Boo. It installs like any normal Windows app — no account, no sign-up.
  2. Ask it anything. Fix a bug, explain a file, plan a feature. It works the way you'd expect a coding agent to.
  3. Click the speaker. Any answer, read aloud, start to finish — highlighted as it goes.

Questions

Is it really free?

Yes. Download it and use it. You bring your own AI provider account, the same way you would with any coding agent.

Do I need an account?

Not for Boo Boo itself. You'll connect an AI provider so it can think — everything else is local.

Does it send my code anywhere?

The voice runs entirely on your machine. Your code goes only to the AI provider you choose, exactly as it would with any other agent.

Why does Windows warn me?

The installer isn't code-signed yet, so Windows flags anything unsigned as unknown. Choose “More info → Run anyway.”

Is there a Mac version?

Not yet. Windows first.
